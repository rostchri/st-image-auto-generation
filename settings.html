Image Auto Generation
When enabled, the extension will also process <pic> tags in user messages (e.g., from Quick Replies). Default: disabled.
When enabled, SillyTavern regex transformations are applied to messages before searching for <pic> tags. Useful if your regex rules transform tags. Default: disabled.
When enabled, REPLACE mode uses SillyTavern's image viewer with zoom, prompt display, and seed regeneration. When disabled, uses simple <img> tags. Default: enabled.
When enabled, each <pic> tag gets its own separate image viewer at that position in the text. When disabled, all images are collected into a single image viewer. Note: Multiple viewers use inline images (click to open), not full SillyTavern image viewer features. Default: disabled.
When enabled, adding <pic> tags to existing messages via edit will automatically trigger image generation. Default: enabled.
Maximum number of times images can be generated for a single message (prevents infinite loops). Also determines how many images are generated per <pic> tag. Set to 0 for unlimited (not recommended). Default: 1.
When enabled, every <pic>-tag is rendered via the comfyui-api endpoint configured in the separate "ComfyUI Workflows" extension (settings drawer). Base-URL and Workflow are pulled from there — no duplicate config here. Disabled by default.
