Image Auto Generation
This will be injected into your chat as a system message. You can use {{char}} and {{user}} placeholders. The prompt should instruct the AI to use <pic prompt="..."/> tags to mark places where images should be generated.
Regex pattern to match image tags in chat messages. Must have one capture group for the image prompt. Default matches <pic prompt="..."/> or <pic prompt="...">.
If enabled, user messages will also be scanned for pic-tags.
If enabled, when a message is edited and new pic-tags are added, those will be processed.
If enabled, ST's regex extension transformations will be applied to the message before searching for pic-tags.
If enabled (and Insert Type = REPLACE): replaces all pic-tags with a single combined image viewer at the end of the message. Otherwise: each pic-tag is replaced with a simple <img> tag at its position.
If enabled, each pic-tag gets its own image viewer at its position in the message. Pairs well with maxImageGenerationsPerMessage > 1.
Maximum number of pic-tags to process per message. Excess tags are ignored.
